PANDUAN UPDATE KASEDITOR PWA v2.0 DI GITHUB PAGES
================================================
1. Ekstrak file KasEditor_PWA_Ready.zip ini.
2. Buka repository KasEditor Anda di GitHub (https://github.com/Rrdwnsyah/KasEditor).
3. Klik 'Add file' -> 'Upload files'.
4. Seret file 'index.html' dan 'sw.js' (atau semua isi folder) ke kotak upload untuk menimpa versi lama.
5. Klik 'Commit changes'.
6. Tunggu 1-2 menit, lalu buka https://rrdwnsyah.github.io/KasEditor/ dan refresh (atau tutup-buka ulang aplikasi PWA di HP).
   Data lokal dan URL API di IndexedDB tetap aman dan tidak terhapus.
