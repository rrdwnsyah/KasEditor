PANDUAN DEPLOY KASEDITOR PWA (3 LANGKAH, TANPA CODING / TANPA GIT)
==================================================================

1. Ekstrak file KasEditor_PWA_Ready.zip ini menjadi 1 folder biasa.
2. Buka https://app.netlify.com/drop (atau Cloudflare Pages -> Direct Upload) di browser laptop.
   Tarik dan lepas (drag & drop) folder hasil ekstrak tadi ke halaman tersebut.
   Dalam beberapa detik akan muncul link HTTPS aplikasi kamu (Rp0 gratis).
3. Buka link HTTPS itu di Chrome (Android) atau Safari (iPhone):
   - Android Chrome: ketuk titik tiga -> "Install app" / "Tambahkan ke layar utama".
   - iPhone Safari : ketuk Share -> "Add to Home Screen".
   - Buka KasEditor -> masuk tab Pengaturan -> Buku & Sinkronisasi ->
     tempel URL API Pusat (/exec) kamu -> ketuk "Simpan & Sambungkan".

Catatan:
- Masalah CORS browser & keamanan URL API sudah otomatis ditangani di dalam kode.
- URL API (/exec) hanya tersimpan lokal di IndexedDB HP kamu (tidak ikut ter-upload).
- Jika sinyal hilang, input video masuk antrean offline dan otomatis terkirim saat online.
